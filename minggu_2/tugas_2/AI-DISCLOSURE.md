# AI Disclosure

## Tools yang digunakan

Saya menggunakan ChatGPT sebagai bantuan dalam mengerjakan penataan visual halaman web.

## Prompt utama

Saya meminta bantuan untuk memeriksa dan memperbaiki CSS pada halaman web Informasi Kepulauan Kei sesuai ketentuan praktikum, terutama terkait custom properties, box-sizing, spacing, typography, card, form, accessibility, focus state, responsive layout, dan visual consistency.

## Saran yang digunakan

Beberapa saran yang digunakan antara lain:
- penggunaan CSS custom properties untuk warna, spacing, dan radius;
- penggunaan `box-sizing: border-box`;
- penggunaan satuan relatif seperti `rem` dan `ch`;
- pembatasan lebar konten menggunakan `max-width`;
- penggunaan `max-width: 100%` pada gambar;
- penggunaan class untuk komponen seperti navigasi dan card;
- penggunaan `:hover`, `:active`, dan `:focus-visible`;
- penambahan focus indicator untuk navigasi dan form;
- penataan layout agar tetap nyaman pada layar sempit.

## Pengujian

Setelah menerapkan perubahan, saya melakukan pengujian secara mandiri melalui browser dan DevTools, termasuk:
- memeriksa tampilan halaman;
- menguji navigasi dengan keyboard;
- memeriksa focus indicator;
- menguji tampilan pada layar sempit;
- menguji zoom 200%;
- melakukan pemeriksaan contrast;
- memeriksa cascade melalui DevTools.

## Perubahan yang saya lakukan sendiri

Saya menyesuaikan kode dengan proyek saya sendiri, termasuk struktur HTML, isi halaman tentang Kepulauan Kei, gambar wisata, teks, nama class, serta melakukan pengujian dan perbaikan CSS berdasarkan hasil yang terlihat pada browser.
